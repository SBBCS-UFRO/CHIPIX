# CHIPIX 1.0.0

- ChimeraX tool menus, running-tool entries and window titles now use CHIPIX. The internal header and release metadata retain CHIPIX 1.0.0.
- Box appearance, movement, resize handles and preset controls are now in Preparation and box under + Customize box. Optional XYZ rotation and residue/atom specification have their own collapsed sections. Scene and image contains background, lighting and image export. Collapsing sections preserves their values.
- New CHIPIX product identity, bundle `ChimeraX-CHIPIX` and `chipix` command.
- Supplied laboratory artwork beside the versioned title and the requested UFRO credit.
- Live, persistent interface translations in English, Spanish, German, French, simplified Chinese, Japanese and Portuguese.
- Localized diagnostics, README, installation guide, user documentation and offline ChimeraX help.
- Standalone source release with its wheel, machine-readable manifest, source manifest, licenses and file checksums.
- Existing rigid Vina/Smina docking, pose import/display, pairwise consensus and reproducibility workflows retained.
- Live search-box position, size and XYZ rotation; native right-button movement, resize handles and rotation, with previous bindings restored when disabled.
- Boxes fitted to native residue/atom specifications as well as the current selection.
- Rounded joins and spherical handles with custom colors/radii; outline, surface mesh, transparent faces and hidden styles.
- Oriented Vina/Smina execution through transformed input copies, original-scene pose recovery and recorded coordinate-frame hashes.
- Independent native 3D distance group with live labels, appearance controls, removal and CSV export.
- Image export with backgrounds, native lighting presets, resolution, supersampling, transparency and overlay controls; scene restored after success or failure.
- Validated JSON style presets and exported image camera/style metadata; updated documentation and translations in all seven languages.
- Real Vina rotated-frame validation and native OpenGL PNG/transparency export tests on ChimeraX 1.12/macOS Apple Silicon.

Scientific scope and known limitations are documented in DOCUMENTATION.md.
