# Motor de prueba disponible en esta copia

`vina_1.2.7_mac_aarch64` es el ejecutable **oficial y sin modificar de AutoDock Vina 1.2.7 para macOS Apple Silicon**. Se descargó para la prueba con el ejemplo 1iep y puede seleccionarse desde **Docking → Ejecutable → Examinar…**. Está fuera del wheel: la extensión no instala motores en el sistema ni altera el PATH.

Origen: [versión oficial v1.2.7](https://github.com/ccsb-scripps/AutoDock-Vina/releases/tag/v1.2.7), archivo [vina_1.2.7_mac_aarch64](https://github.com/ccsb-scripps/AutoDock-Vina/releases/download/v1.2.7/vina_1.2.7_mac_aarch64).

```text
823c2bbacf26d72183861322345f0a89736aca66c8e81054c66f93af5ad623f1
```

Esta es una huella calculada localmente; la API de esa versión no publicaba un digest del proveedor. El archivo mantiene su licencia Apache 2.0, incluida en `AutoDock-Vina-LICENSE`. Código fuente: [ccsb-scripps/AutoDock-Vina, v1.2.7](https://github.com/ccsb-scripps/AutoDock-Vina/tree/v1.2.7).

En otras plataformas usa el ejecutable oficial correspondiente. Smina se configura de forma independiente.
